# Product Overview

**Avrora Area** is an advanced AI collaboration platform built around the concept of **Sfera** (spherical collaborative spaces) and **Orbit** (personality trajectories).

## Key Features

- **Sfera Spaces**: Public, private, and DAO collaborative environments with role-based access (owner, admin, member, viewer)
- **AI Agents**: Multiple AI assistants including Avrora AI (main assistant) and Claude Code (specialized for code work)
- **Message Threading & Forking**: Reply to messages and fork discussions into new Sfera spaces
- **Artifacts**: Generated content (text, code, images, sheets, mini-apps, charts, games) tied to Sfera and messages
- **Magic Link Authentication**: Passwordless login via email tokens
- **MCP Integration**: Model Context Protocol for extending AI capabilities with external tools
- **Multi-Provider AI**: Support for Anthropic (Claude), OpenAI (GPT-4), Google (Gemini), xAI (Grok)
